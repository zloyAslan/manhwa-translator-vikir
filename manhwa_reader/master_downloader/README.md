# ⚡ Manhwa Master Downloader — Telegram Cloud Relay

Автономна утиліта для передачі глав манхви (PDF, ZIP, CBZ) з відкритих Telegram-каналів у ваше приватне хмарне сховище без використання місця на диску (100% In-Memory Streaming через `io.BytesIO`).

---

### 🌟 Що робить ця утиліта:
1. **Запитує потрібні параметри перед початком**:
   - **Канал-джерело**: посилання (`https://t.me/...`) або `@username` відкритого каналу.
   - **Повна назва тайтлу**: записується у круглих дужках `( )`, наприклад `(Помста залізно-кровного хорта)`.
   - **Скорочена назва / код**: записується у квадратних дужках `[ ]`, наприклад `[ПЗ-КХ]`.
   - **Локалізація**: мова перекладу, наприклад `[UA]` або `[Ан.]`.
   - **Номер або діапазон глав**: наприклад `1-30`, `5` або Enter для всіх.
   - **Пошуковий фільтр**: фільтрація повідомлень за ключовим словом.
2. **Стрімінг через оперативну пам'ять (RAM)**:
   - Файл завантажується в буфер оперативної пам'яті (`io.BytesIO`).
   - Жоден файл не зберігається на жорсткому диску.
   - Зберігає структуру назви файлу: `[ПЗ-КХ] 001 (Помста залізно-кровного хорта) [UA].pdf`.
   - Додає теги до повідомлення для швидкого пошуку: `#TITLE_ПЗ_КХ #CH_001 #UA`.
   - Після відправки пам'ять моментально вивільняється (`gc.collect()`).
3. **Один канал — багато тайтлів**:
   - Оскільки кожен файл має унікальний код у назві `[ПЗ-КХ]` та хештеги, ви можете завантажувати десятки різних тайтлів в один приватний канал без плутанини.
   - Утиліта оновлює `cloud_index.json` та створює закріплений каталог у вашому каналі-сховищі.
