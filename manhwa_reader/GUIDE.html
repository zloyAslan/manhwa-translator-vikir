⚡ Quick Start in 3 Easy Steps
1

Unpack & Run

Extract the folder anywhere on your PC (Desktop, disk D:, USB drive). Run ManhwaReader.exe or execute python reader.py. The library folder will be created automatically.

2

Connect Telegram Bot (Optional, for downloading)

Open the «⚡ TG Downloader» tab. Click «🤖 Bot Token», paste your bot token from @BotFather and save. No phone numbers, SMS, or passwords needed!

3

Download & Enjoy Reading

Enter an open Telegram channel (e.g. @Manhwa_Weebs or link) ➔ enter chapter number (e.g. 1 or 1-10) ➔ click «🚀 Start Download». Chapters appear instantly in your library!

🎉 Dual Reading Mode: Read directly from high-resolution PDF or unpack to lightning-fast JPEG strips anytime via the button in the reader header!
🤖 Free Telegram Bot Setup (1 Minute)

Our downloader uses the official Telegram Bot API to download PDF manhwa chapters from open channels. It requires zero phone logins and is 100% secure.

  1. Open @BotFather in Telegram.
  2. Send the command /newbot.
  3. Enter any display name for your bot (e.g. MyReaderBot).
  4. Enter a unique username ending with bot (e.g. my_reader_super_bot).
  5. Copy the received HTTP API token (format: 8599785351:AAFNZkDk1Gl...).
  6. In Manhwa Reader ➔ open «⚡ TG Downloader» ➔ click «🤖 Bot Token» ➔ paste and click Save!
