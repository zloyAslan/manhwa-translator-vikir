# ⚔️ Манхва Перекладач поверх екрану (Чібі Вікір) • Anki Pro Edition

Повноекранний віджет-перекладач для читання манхви з **нейромережевим OCR (RapidOCR)**, **прямою синхронізацією з Anki** та **захопленням кадрів манхви для візуальної пам'яті**.

---

## 🚀 Гарячі клавіші:

| Клавіша | Дія | Опис |
|---|---|---|
| **`Alt + A`** | 🤖 **ШІ-розбір (Gemini)** | Розбір речення з ідіомами, сталі вирази та чат з Вікіром у форматі месенджера. |
| **`Alt + E`** | 📷 **Захоплення слова** | Виділіть репліку мишкою. Автоматично зчитує текст, перекладає та показує хмаринки. |
| **`Alt + W`** | 📝 **Захоплення речення** | Ховає вікно, дає виділити довге речення з манхви та автоматично вставляє в Anki. |
| **`Alt + D`** | 🖼️ **Захоплення арту (панелі)** | З'являється рамка з фіксованими пропорціями картки (16:10) для кадрування малюнка персонажа в Anki. |
| **`Alt + Q`** | 💬 **Відкрити перекладач** | Швидко викликати поле вводу або перекласти скопійований текст. |
| **`Enter`** | ➜ **Перекласти / Надіслати** | Миттєвий переклад або відправка репліки в чат. |
| **`Esc`** | ✕ **Скасувати / Сховати** | Закрити активне діалогове вікно або вийти з режиму виділення. |

---

## 🎴 Новий процес додавання карток в Anki:

1. Під час читання манхви виділіть слово через **`Alt + E`** або відкрийте ШІ-розбір через **`Alt + A`**.
2. Вікір показує переклад або розбір із кнопками **`⭐ Створити картку в Anki`** / **`⭐ В Anki`**.
3. Відкривається зручне віконце створення картки з полями **Слово**, **Речення**, **Переклад** (+ арт через **`Alt + D`**).
4. Натисніть **`✅ Додати в Anki (англ манхва)`**:
   - Картка **миттєво створюється прямо у вашій відкритій програмі Anki на ПК** через AnkiConnect (без накопичення зайвих файлів на диску)!

---

## 🛠️ Що виправлено та вдосконалено:

1. **Виправлено розпізнавання літери «D»**:
   - Додано нейромережевий рушій **RapidOCR (ONNX)**, оптимізований для коміксних шрифтів. Більше жодних плутанин `D` з `P` (`DAYS`, `HOUND`, `HAD`, `DEVOTED` розпізнаються бездоганно).
2. **Пряме з'єднання з вашим Anki**:
   - Програма автоматично підключається до порту **8766** вашого AnkiConnect.
   - Заповнює саме ваші поля: **`Слово`**, **`Речення`** та **`Переклад`** (+ прикріплений арт).
3. **Озвучення вимови слів 🔊**:
   - Виправлено вивід аудіо: тепер вимова спрямовується через нативний системний мікшер Windows безпосередньо у ваші підключені навушники чи колонки.
4. **Матова палітра без білих смуг**:
   - Повністю прозорий контейнер прокрутки ліквідував білі смуги.
   - Верхня тонка лінія зі стильним градієнтом: бурштин ➜ синій ➜ м'ята.
5. **Хвостик репліки**:
   - Спрямований горизонтально точно на обличчя Вікіра.
