# ⚔️ M_Translate & Manhwa Reader Ecosystem (v2.0)
> **Dark Fantasy Edition • Standalone Portable Suite**  
> Повноцінний комплекс для читання манхви/вебтунів в оригіналі, миттєвого оверлейного перекладу з екрана, ШІ-асистента Gemini та інтервального вивчення слів через Anki.

---

## 📦 Склад екосистеми та доступні програми

У папці `exe_programs/` зібрано автономні portable-версії (не потребують встановлення Python чи бібліотек):

1. **`m_reader_t.exe` (Комбайн / All-in-One)**:
   - Об'єднує читалку вебтунів та оверлейний екранний перекладач в одному процесі.
   - Кнопка **«⚔️ Translate»** на панелі читалки миттєво відкриває оверлейний перекладач.
2. **`lm_reader.exe` (Автономна Читалка манхви & новел)**:
   - Безшовний вебтун-скрол без білих ліній і пауз.
   - Адаптивне/фіксоване фонове підвантаження наступних розділів.
   - 3-шаровий звуковий рушій (Музика + Ембієнт + SFX екшен-ефекти).
   - Вбудований хмарний стрімінг у RAM та збереження закладок.
3. **`m_translate.exe` (Оверлейний екранний перекладач)**:
   - Працює поверх **будь-яких програм** (браузери Chrome/Firefox, ігри, сторонні читалки).
   - Офлайн нейромережеве розпізнавання тексту **RapidOCR (ONNX)**, заточене під коміксні шрифти.
   - ШІ-розбір ідіом, сленгу та контексту через Google Gemini.
   - Створення карток Anki в один клік (через AnkiConnect порт 8766).

---

## ⚡ Швидкий старт для користувачів

1. Завантажте та запустіть **`m_reader_t.exe`** (або окремо `lm_reader.exe` / `m_translate.exe`).
2. **Читання**:
   - Відкрийте вкладку **«Хмарне сховище»** для миттєвого читання без завантаження на диск або **«TG Завантажувач»** для збереження у локальну папку `library/`.
   - Гортайте мишкою або клавішами **`S`** / **`Down`**.
   - Натисніть **`H`** для увімкнення Zen-режиму (приховати панелі) або **`F11`** для повного екрана.
3. **Переклад**:
   - Натисніть **`Alt + E`** (або **`F12`**) і виділіть мишкою репліку на екрані.
   - З'явиться стильний бабл із перекладом, розбором і озвученням.
   - Натисніть **`Alt + W`** для захоплення речення або **`Alt + D`** для кадрування арту персонажа на картку Anki.

## 🤖 Налаштування ШІ Gemini та Anki

- **Власний безкоштовний ключ Gemini**:
  1. Перейдіть на [Google AI Studio](https://aistudio.google.com/) та згенеруйте безкоштовний ключ (`Create API Key`).
  2. Вставте його у полі **Налаштування ➔ AI Gemini** у перекладачі або читалці.
  3. Ключ зберігається виключно локально на вашому комп'ютері.
- **Синхронізація з Anki**:
  - Запустіть десктопний Anki із плагіном **AnkiConnect** (код: `2055492159`).
  - Програма автоматично створює картки з темним неоновим стилем у колоді `англ манхва`.
