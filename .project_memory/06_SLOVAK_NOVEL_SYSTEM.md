# 🇸🇰 06. Словацька навчальна система для новел (Slovak Novel System B1-B2)

## 1. Загальна концепція та місія напрямку
Цей напрямок розроблений для швидкого переходу та закріплення словацької мови на рівні **B1-B2** за допомогою активного читання новел / ранобе (Light Novels / Web Novels).

Система складається з трьох тісно пов'язаних компонентів:
1. **Інтеграція читання новел у manhwa_reader** (прихована вкладка «Новели / Ранобе», адаптована читалка Zen/Dark Mode).
2. **Консольна утиліта пакетного перекладу глав** (переклад глав за допомогою LLM/Gemini, архівація оригіналів, експорт у бібліотеку).
3. **Окремий спеціалізований перекладач для новел (Slovak Novel Translator)** (полегшений екземпляр перекладача без OCR, швидке копіювання виділеного тексту через Alt+W, спрощені Anki-картки, ШІ-консультант Gemini).

---

## 2. Компонент 1: Читалка новел у manhwa_reader

### 2.1. Управління видимістю вкладки «Новели / Ранобе»
- **Прихована за замовчуванням:** Вкладка «Новели / Ранобе» у головній бібліотеці прихована, доки в системі немає жодної завантаженої новели.
- **Авто-активація:** Щойно користувач завантажує першу новелу/ранобе (через Telegram Downloader) або додає підтримуваний файл у папку бібліотеки новел, вкладка стає видимою в інтерфейсі.

### 2.2. Оновлення Telegram Downloader
- **Розміщення чекбокса:** Чекбокс розміщується у верхній частині панелі завантажувача (вище стандартних фільтрів форматів манхви), витриманий у загальному стилі проєкту (Dark Fantasy QCheckBox).
- **Назва та підказка:**
  - Текст: `Новела / Ранобе (EPUB / DOCX / TXT)`
  - Дрібний підпис-підказка під чекбоксом: пояснення, що файл буде спрямовано до бібліотеки новел з автоматичним розпізнаванням глав.

### 2.3. Режим читання новел (Zen / Dark Mode)
- **Точка входу:** Натискання кнопки **«Читати»** у карточці тайтла у вкладці новел.
- **Візуальний стиль та інтерфейс:**
  - Мінімалістичний чистий текстовий рідер (Zen/Dark Mode).
  - Красивий монотонний темний фон (глибокий графіт `#12131A` / `#0D0E15` без візуального шуму).
  - Текст: контрастний білий `#FFFFFF`, комфортний інтерліньяж (line-height 1.6–1.8), регульований розмір шрифту.
  - Виділення тексту: живий нативний текст (QTextBrowser / QPlainTextEdit / QWebEngine) з можливістю нормального системного виділення мишкою.
- **Прогрес прочитаного:**
  - Відображення прогресу читання глави/книги з точністю до одного знака після коми у відсотках (наприклад: `14.3%`, `58.0%`).
  - Збереження позиції скролу та глави в локальну БД/конфіг при закритті.
- **Підтримувані формати:**
  - `EPUB`
  - `DOCX`
  - `TXT`

## 3. Компонент 2: Консольна утиліта пакетного перекладу глав

### 3.1. Призначення та філософія
- Окремий легкий скрипт / консольна утиліта CLI **без зайвих важких GUI**.
- Призначена для пакетної автоматизованої обробки сирих глав новел (з англійської/корейської/інших мов) на **словацьку мову (Slovenčina)** для подальшого вивчення.

### 3.2. Рушії перекладу
- **Базовий рушій:** Google Gemini API (промпти заточені під збереження художнього стилю, контексту реплік та граматики рівня B1-B2 словацької мови).
- **Модульність:** Архітектурна підготовка для підключення альтернатив (DeepL Free/Pro API, безкоштовні перекладачі або локальні LLM).

### 3.3. Пайплайн файлової обробки
```text
Raw Chapters (Вхід) ──► CLI Translator (Gemini/DeepL) ──► Бібліотека Читалки (EPUB/TXT)
                             │
                             └──► Авто-архівація вихідних файлів у archive/
```
1. Вичитка тексту глави з вхідної черги.
2. Сегментація на безпечні за розміром токенів блоки зі збереженням абзаців.
3. Переклад на словацьку мову.
4. Збереження перекладеного файлу у відповідну директорію бібліотеки новел `manhwa_reader`.
5. Автоматичне переміщення оригінальних оброблених файлів у теку `archive/`.

## 4. Компонент 3: Окремий спеціалізований перекладач (Slovak Novel Translator)

### 4.1. Автономність програми
- **НЕ є розширенням загального оверлею манхви**, а є окремим спеціалізованим полегшеним інструментом (`slovak_novel_translator.py` / окремий `.exe` у папці утиліт).
- Створений для персонального швидкого читання користувача без перевантаження ресурсів системи.

### 4.2. Спрощення ядра та відмова від OCR
- Оскільки текст у читалці новел живий (selectable), з цього модуля **повністю вилучено OCR (RapidOCR / ONNX), алгоритми захоплення скріншотів та розпізнавання картинок**.
- Це робить утиліту ультралегкою, миттєвою та компактною за розміром.

### 4.3. Мовний напрямок та інтерфейс
- **Суворий мовний вектор:** **Словацька (SK) ➔ Українська (UA)**.
- Інтерфейс виключно українською мовою, без надлишкових селекторів вибору мов.

### 4.4. Хоткей Alt+W (Миттєве контекстне захоплення)
1. Користувач читає новелу та натрапляє на незнайоме слово/речення.
2. Натискає глобальний хоткей `Alt + W`.
3. Вікно перекладача автоматично ховається/мінімізується, надаючи користувачу можливість виділити речення мишкою.
4. Програма автоматично перехоплює виділений фрагмент (через системний буфер обміну / mouse selection без жодного OCR).
5. Виділене речення автоматично підставляється у відповідне поле контекстного речення Anki-діалогу.

### 4.5. Спрощена картка Anki
На відміну від карток манхви (де генерується пропорційний скріншот арту 16:10), картка для новел спрощена та оптимізована під текстову пам'ять:
- **Поле 1:** Слово (Словацька)
- **Поле 2:** Контекстне речення (Словацька з підсвічуванням/bold слова)
- **Поле 3:** Переклад (Українська)

### 4.6. ШІ-режим запитань (Gemini Assistant)
- Вбудований швидкий чат/режим пояснення для складних зворотів, словацьких фразеологізмів чи специфічної граматики B1-B2.
- Запити формуються в один клік: пояснення значення в контексті поточної сцени новели українською мовою.
