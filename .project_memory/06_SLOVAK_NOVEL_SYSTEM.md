# 🇸🇰 06. Словацька навчальна система для новел (Slovak Novel System B1-B2)

## 1. Загальна концепція та місія напрямку
Цей напрямок розроблений для швидкого переходу та закріплення словацької мови на рівні **B1-B2** за допомогою активного читання новел / ранобе (Light Novels / Web Novels).

Система складається з трьох тісно пов'язаних компонентів:
1. **Інтеграція читання новел у `manhwa_reader/novel_reader`** (вкладка «Новели / Ранобе», адаптована читалка Zen/Dark Mode з парсерами EPUB/DOCX/TXT).
2. **Консольна утиліта пакетного перекладу глав `novel_batch_translator/`** (переклад глав з англійської на словацьку через Gemini/DeepLX).
3. **Окремий спеціалізований перекладач `slovak_translator/`** (полегшений автономний додаток без OCR, швидке копіювання виділеного тексту через Alt+W, Anki з транскрипцією IPA, студійний Microsoft Edge Neural TTS).

---

## 2. Компонент 1: Читалка новел у manhwa_reader

### 2.1. Локація та структура модуля
- Модуль розташований безпосередньо у `manhwa_reader/novel_reader/`.
- Файли:
  - `novel_window.py` (`NovelReaderWindow`, `NovelTextBrowser`): віджет читання з безшовним скролом та перемиканням глав (хоткеї `W` / `E`).
  - `parsers/novel_parser.py` (`EpubParser`, `DocxParser`, `TxtParser`): парсери глав з очищенням HTML.

### 2.2. Управління видимістю вкладки «Новели / Ранобе»
- **Прихована за замовчуванням:** Вкладка «Новели / Ранобе» у головній бібліотеці прихована, доки в системі немає жодної завантаженої новели.
- **Авто-активація:** Щойно користувач завантажує першу новелу/ранобе (через Telegram Downloader) або додає підтримуваний файл у папку бібліотеки новел, вкладка стає видимою в інтерфейсі.

### 2.3. Telegram Downloader з фільтрацією дублікатів
- **Фільтр дублікатів глав (Newest/Oldest/All):**
  - Вирішує проблему, коли в каналі Telegram викладено старий онгоінг і новий перезапуск/реліз з однаковою нумерацією (наприклад, `@Stal_storonnikom_zlodeev`).
  - Опція `⚡ Завантажувати новіші (найсвіжіший реліз / перезапуск)` — автоматично бере найновіші повідомлення та пропускає застарілі копії.
  - Постійні сесії Telethon зберігаються у файлах (`tg_bot_session.session`, `tg_cloud_relay_session.session`) для усунення помилок `FloodWait / ImportBotAuthorizationRequest`.
- **Чекбокс збереження новел:**
  - `Новела / Ранобе (EPUB / DOCX / TXT)` спрямовує завантажені файли у `novels_library/`.

### 2.4. Режим читання новел (Zen / Dark Mode)
- **Точка входу:** Натискання кнопки **«Читати»** у карточці тайтла у вкладці новел.
- **Візуальний стиль та інтерфейс:**
  - Мінімалістичний чистий текстовий рідер (Zen/Dark Mode).
  - Красивий монотонний темний фон (глибокий графіт `#12131A` / `#0D0E15` без візуального шуму).
  - Текст: контрастний білий `#FFFFFF`, комфортний інтерліньяж (line-height 1.6–1.8), регульований розмір шрифту.
  - Виділення тексту: живий нативний текст (`NovelTextBrowser`) з можливістю нормального системного виділення мишкою.
- **Прогрес прочитаного:**
  - Відображення прогресу читання глави/книги з точністю до одного знака після коми у відсотках (наприклад: `14.3%`, `58.0%`).
  - Збереження позиції скролу та глави в локальну БД/конфіг при закритті.

## 3. Компонент 2: Консольна утиліта пакетного перекладу глав (`novel_batch_translator/`)

### 3.1. Призначення та розміщення
- Розташована в окремій директорії: `novel_batch_translator/`.
- Запуск через ярлик `3. Пакетний Перекладач Глав Новел (CLI).lnk` або батник `run_novel_batch_translator.bat`.
- Призначена для пакетної автоматизованої обробки сирих глав новел (з англійської) на **словацьку мову (Slovenčina)** для подальшого вивчення.

### 3.2. Рушії перекладу
- **Базовий рушій:** Google Gemini API (промпти заточені під збереження художнього стилю, контексту реплік та граматики рівня B1-B2 словацької мови).
- **Альтернативи:** DeepLX локальний сервер (`http://127.0.0.1:1188/translate`).

## 4. Компонент 3: Окремий спеціалізований перекладач (`slovak_translator/`)

### 4.1. Автономність та розміщення
- Розташований у папці `slovak_translator/` з власним скомпільованим білдом `slovak_translator.exe` (розмір ~43 МБ).
- Запуск через ярлик `2. Перекладач Словацьких Новел (SK-UK).lnk`.
- Повністю ізольований від оверлею манхви.

### 4.2. Спрощення ядра та відмова від OCR
- Оскільки текст у читалці новел живий (selectable), з цього модуля **повністю вилучено OCR (RapidOCR / ONNX), алгоритми захоплення скріншотів та розпізнавання картинок**.
- Модуль ультралегкий і відкривається миттєво.

### 4.3. Високоякісна студійна озвучка (Edge Neural TTS) та транскрипція
- **Нейронний рушій Microsoft Azure Neural (`sk-SK-ViktoriaNeural`):**
  - Використовує бібліотеку `edge-tts` — ідеальна дикція, наголоси на перший склад, точна вимова м'яких приголосних (`ď`, `ť`, `ň`, `ľ`) та дифтонгів (`ô`, `ia`, `ie`).
  - Відмова від локального Piper TTS через дефекти вимови та злиття складів.
- **Швидкість озвучки:**
  - За замовчуванням: `-15%` (👌 помірний темп для комфортного сприйняття на слух).
  - Доступні пресети в налаштуваннях: `-25%` (🐢 повільно), `-15%`, `+0%` (⚡ стандартна розмовна).
- **Кнопки озвучки `🔊`:**
  - Додано в рядок пошуку хмарки перекладу.
  - Додано у картку слова разом з автоматичною міжнародною транскрипцією IPA (наприклад: `[podzemneː]`, `[kraːʎofstʋo]`).
  - Додано у діалогове вікно Anki для швидкого прослуховування перед збереженням.

### 4.4. Хоткей Alt+W (Миттєве контекстне захоплення)
1. Користувач читає новелу та натрапляє на незнайоме слово/речення.
2. Натискає глобальний хоткей `Alt + W`.
3. Вікно перекладача автоматично ховається, користувач виділяє речення мишкою.
4. Програма автоматично перехоплює виділений фрагмент через буфер обміну.
5. Виділене речення автоматично підставляється у поле контексту Anki-діалогу.

### 4.5. Спрощена картка Anki
- **Поле 1:** Слово (Словацька) + фонетична транскрипція IPA
- **Поле 2:** Контекстне речення (Словацька з підсвічуванням/bold слова)
- **Поле 3:** Переклад (Українська)

### 4.6. ШІ-режим запитань (Gemini Assistant)
- Вбудований швидкий чат/режим пояснення для складних зворотів, словацьких фразеологізмів чи специфічної граматики B1-B2 через модель `gemini-flash-lite-latest`.
