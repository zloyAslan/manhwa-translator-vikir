# 🔍 04. Детальний аналіз модулів та кодової бази (Modules Deep Dive)

## 1. Вхідні точки запуску

1. **`main.py`** (`ManhwaTranslatorApp`):
   - Запуск окремого перекладача.
   - Ініціалізує плаваючий неоновий бейдж (`ChibiMascot`), вікно комікс-бабла (`BubbleWindow`), оверлеї OCR та вирізання арту, системний трей (QSystemTrayIcon).
   - Реєструє глобальні хуки клавіатури через `keyboard` (Windows LL Hook) та зв'язує їх через Qt-сигнали (`HotkeySignal`), щоб уникнути викликів GUI з не-GUI потоків.

2. **`manhwa_reader/reader.py`** (`ManhwaReaderWindow`):
   - Головне вікно читалки манхви.
   - Підтримує 3 ключові режими:
     - Локальна бібліотека (`library/`).
     - Хмарне сховище (стрімінг через `cloud_stream.py`).
     - Telegram Завантажувач (модуль пошуку та скачування).
   - Безшовний вертикальний скрол (Webtoon strip) оптимізований під довгі суцільні полотна.
   - Режим Zen (`H`) — приховує панелі; повноекранний режим (`F11`).

3. **`suite_main.py`**:
   - Об'єднаний пусковий модуль (Suite / Комбайн), що одночасно стартує читалку і реєструє віджет-перекладач в єдиному додатку `QApplication`.

## 2. Модулі перекладача (M_Translate)

### 2.1. `ocr_snipper.py` (`SnippingOverlay`)
- Напівпрозоре повноекранне полотно для виділення прямокутної області мишкою.
- Працює у двох режимах:
  - `word` — швидке розпізнавання слова або короткої фрази (гаряча клавіша `Alt + E` або `F12`).
  - `sentence` — розпізнавання цілого контекстного речення (`Alt + W`).
- Використовує рушій **RapidOCR (ONNX Runtime)**:
  - Проходить пре-процесинг зображення для чіткого зчитування чорно-білих та стилізованих коміксних шрифтів.
  - Повністю ліквідована проблема плутанини між літерами `D` та `P`.

### 2.2. `panel_cropper.py` (`PanelCropper`)
- Оверлей захоплення арту манхви (`Alt + D`).
- Примусово утримує пропорцію **16:10**, щоб вирізаний малюнок ідеально вкладався в шапку картки Anki.
- Зберігає кадр у буфер та тимчасовий файл, генеруючи пряме посилання для вставки в Anki-діалог.

### 2.3. `bubble_window.py` & `bubble_widgets.py`
- Вікно відображення перекладу у вигляді комікс-хмаринки (`ComicBubbleFrame`).
- Включає:
  - Поле введення або поточне розпізнане слово з прапорцями мов.
  - Транскрипцію (білий курсив) та кнопку звуку (🔊).
  - Основні значення, синоніми та визначення з локального словника/кешу.
  - Кнопку переходу до Anki (`⭐ Створити картку в Anki`).
  - Кнопку ШІ-розбору (`🤖 AI Gemini`).
  - Діалог налаштувань (`LanguageSettingsDialog`): вибір мов, конфігурація Anki (порти 8766/8765), ключ Gemini.

### 2.4. `anki_dialog.py` (`AnkiCardDialog`)
- Окреме ергономічне модальне вікно для фінальної підготовки картки перед відправкою в колоду:
  - Поле **Слово** (Target word).
  - Поле **Контекстне речення** (з кнопкою `Alt + W` для дозахоплення речення з манхви).
  - Поле **Переклад / Пояснення**.
  - Слот для **Арт-кадру манхви** (з кнопкою `Alt + D` для захоплення).
  - Кнопка швидкого додавання в активний Anki («✅ Додати в Anki (англ манхва)»).

### 2.5. `anki_service.py` (`AnkiService`)
- Взаємодіє з десктопним додатком Anki через REST API плагіна `AnkiConnect`.
- Перевіряє доступність портів `8766` та `8765`.
- Автоматично створює або перевіряє наявність моделі нотатки з полями `Слово`, `Речення`, `Переклад`, `Зображення`.
- Відправляє бінарні дані артів у медіа-теку Anki через дію `storeMediaFile`.
- Fallback-режим: створення та експорт офлайн `.apkg` файлів, якщо AnkiConnect вимкнений.

### 2.6. `ai_service.py` & `ai_chat_window.py`
- Інтеграція з Google Gemini API.
- Промпт-шаблони, заточені під манхву: пояснення образних виразів, бойового та магічного сленгу, скорочень, граматичних конструкцій.
- Інтерактивне вікно чату з маскотом Вікіром.
- Можливість одним кліком згенерувати з відповіді ШІ картку для Anki.

### 2.7. `dictionary_service.py`
- Робота з базою `cache.db` (SQLite).
- Забезпечує миттєву видачу перекладів для вже бачених слів навіть без доступу до мережі.
- Зберігає історію запитів із можливістю пошуку та очищення.

### 2.8. `localization.py`
- Мультиязичний словник локалізації (функція `tr(key)`).
- Підтримувані мови інтерфейсу: **Українська (`uk`)**, **English (`en`)**, **Русский (`ru`)**.

## 3. Модулі Читалки (Manhwa Reader)

### 3.1. `manhwa_reader/reader.py` (`ManhwaReaderWindow`, `WebtoonScrollCanvas`, `LibraryPage`)
- Головний центр управління читанням манхви та вебтунів.
- **`WebtoonScrollCanvas`**: Полотно вертикального безшовного скролу. Відображає сторінки PDF / JPG стрічок, керує масштабуванням (50%–200% з кроком 10%), режимами фону та плавним скролом коліщатком/клавішами.
- **Кастомний рендер підкладки полотна (`paintEvent`)**:
  - Чорний фон (`#000000`) та білий фон (`#ffffff`) малюються через безпосередню підкладку у `paintEvent` полотна.
  - Прозорий режим (`transparent`): підкладка полотна не малюється взагалі, залишаючи віджет прозорим, завдяки чому просвічується темний живий ембієнт-фон самої програми (`AmbientBackgroundWidget`).
  - Миттєве перемикання кольорів на льоту без артефактів чи блокування альфа-каналу Qt.
- **Інтеграція звукового рушія**: Відслідковує активну сторінку та вертикальну чверть полотна у реальному часі через `on_scroll`, викликаючи відповідні звукові події `SoundEngine.on_scroll_position()`.
- **`NovelReaderWindow` інтеграція**: Вбудоване відкриття текстових новел без скидання стану бібліотеки.

### 3.2. `manhwa_reader/sound_system/` (Атмосферний звуковий комплекс v1.2)
- **`sound_engine.py` (`SoundEngine`)**:
  - Апаратне відтворення через `PyQt6.QtMultimedia` (`QMediaPlayer`, `QAudioOutput`).
  - Фоновий ембієнт-канал (Player A / B) з апаратним кросфейдом 1.4 с для музики та 1.0 с для середовища.
  - **Dynamic Multi-SFX Voice Pool (6 каналів)**: незалежне одночасне програвання комбінованих ефектів через кому (наприклад `"neighing,sword_clash"`, `"monster_roar,heavy_strike"`).
  - Підтримка вибору довільної папки для звуків (`sounds_path`) у налаштуваннях.
  - Миттєве завантаження кешованого `sound_timeline.json` (< 1 мс).
- **`ai_sound_analyzer.py` (`AISoundAnalyzer`)**:
  - Обробка повного PDF розділу манхви єдиним запитом через Gemini Vision API.
  - **100% Динамічне сканування (`scan_layered_sound_pools`)**: файли в `ambient/`, `ui/`, `my_sounds/`, `sfx/` підтягуються без жодного хардкоду.
  - Поділ сторінок на 4 чверті (`.0`, `.1`, `.2`, `.3`), генерація 3-шарового звукового сценарію (`bg`, `amb`, `sfx`).
  - Автоматичне збереження `sound_timeline.json` у теку глави.

### 3.3. `manhwa_reader/novel_reader/` (Модуль читання новел)
- **`novel_window.py` (`NovelReaderWindow`, `NovelTextBrowser`)**:
  - Мінімалістичний Zen-інтерфейс (темний графіт `#12131A`, білий контрастний текст).
  - Підтримка виділення живого тексту, збереження точного прогресу читання (`X.X%`).
- **`parsers/novel_parser.py`**:
  - Парсери форматів `EPUB`, `DOCX`, `TXT` з очищенням від зайвих HTML-тегів.

## 4. Внутрішні інструменти розробника (⚠️ Developer-Only / Не для людей)

> [!CAUTION]
> Наступні модулі призначені **виключно для автора проєкту** і не входять до стандартного користувацького дистрибутиву:

1. **`slovak_translator/` (`slovak_translator.exe`)**:
   - Автономний перекладач словацьких новел (Slovak -> Ukrainian).
   - Повністю вирізано OCR для максимальної швидкості та легкості.
   - Миттєвий перехоплювач подвійного кліку / виділення миші через WinAPI `WH_MOUSE_LL` (`SlovakMouseWatcher`).
   - Автоматичне приховування вікна по `Alt + W` для зручного читання контексту.
   - Студійна словацька нейро-вимова `sk-SK-ViktoriaNeural` через Edge-TTS та генератор транскрипцій IPA.
   - Асинхронний Anki-модуль (`SlovakAnkiSaveWorker`) з авто-підтримкою моделей без зависання UI.
2. **`novel_batch_translator/` (`novel_batch_translator.py`)**:
   - Консольний CLI-скрипт для масового перекладу англійських розділів новел на словацьку мову через Google Gemini або локальний сервер DeepLX.
3. **`manhwa_reader/downloader.py` & `tg_cloud_relay.py` (Telegram Downloader)**:
   - Особистий завантажувач розділів із закритих/відкритих Telegram каналів через клієнт `Telethon`.
   - Фільтрація дублікатів (Newest/Oldest/All) та підтримка постійних сесійних файлів.
4. **`manhwa_reader/sound_system/sound_studio.py` (Звукомікшер та бейкер)**:
   - Робоча станція саунд-дизайнера для нарізання, нашарування аудіодоріжок і випікання безшовних 16-бітних WAV фонограм.
