# 🎨 03. Дизайн-система та фірмовий стиль (Design System & Style Guide)

> **КРИТИЧНО ДЛЯ ВСІХ МАЙБУТНІХ СЕСІЙ:** Будь-який новий екран, кнопка, діалог чи віджет **ЗОБОВ'ЯЗАНІ** суворо дотримуватися нижченаведених кольорів, стилів та правил геометрії! Заборонено використовувати стандартні сірі віджети Windows чи довільні випадкові кольори.

---

## 1. Концепція стилю: «Dark Fantasy & Cyber-Comic»

Стиль натхненний темним фентезі та сучасними вебтунами/манхвами («Повернення залізнокровного пса-гончака» / Вікір):
- **Глибокі матові темні площини** (без брудного сірого та без засліплюючого чистого білого).
- **Магічні неонові градієнти:** Золотий бурштин (ранги, рівні, сила) та кібер-бірюза / м'ята (руни, мана).
- **Комікс-елементи:** Акуратні хвостики баблів, пігулки хоткеїв (Kbd), акцентні плашки статусів.

---

## 2. Офіційна палітра кольорів

### Основні фони (Backgrounds):
- **`--bg-deep`**: `#090B10` — Найтемніший фон вікон, налаштувань, читалки.
- **`--bg-card`**: `rgba(18, 22, 34, 0.90)` або `#121622` — Фоновий колір карток, хмаринок, діалогів.
- **`--bg-overlay`**: `rgba(13, 16, 26, 0.85)` або `#0D101A` — Панелі вкладок, списки, поля введення.
- **`--card-border`**: `rgba(255, 255, 255, 0.08)` або `#262B3D` — Тонкі делікатні межі.

### Акцентні кольори (Accents & Highlights):
- **Gold / Amber (Бурштин/Золото):**
  - Одинарний колір: `#F59E0B`
  - Градієнт: `linear-gradient(135deg, #F59E0B 0%, #D97706 100%)`
  - Застосування: Головні кнопки дії (CTA), логотип, значок Anki, важливі статуси.
- **Cyan / Mint (Бірюза / М'ята):**
  - Одинарний колір: `#2DD4BF`
  - Градієнт: `linear-gradient(135deg, #2DD4BF 0%, #0D9488 100%)`
  - Застосування: Озвучення, інформаційні плашки, транскрипція, другорядні акценти.
- **Electric Blue (Синій магічний):**
  - Одинарний колір: `#3B82F6`
  - Градієнт у шапках: Золото ➜ Бірюза ➜ Синій (`linear-gradient(90deg, #F59E0B, #2DD4BF, #3B82F6)`)
- **Небезпека / Видалення (Danger):**
  - `#EF4444` / `#F87171` (бордовий напівпрозорий фон `rgba(239, 68, 68, 0.15)`).

### Текст (Typography Colors):
- **Основний текст:** `#F3F4F6` (м'який світло-сірий, не б'є по очах при тривалому читанні).
- **Вторинний текст (Muted):** `#9CA3AF` / `#6B7280`.
- **Транскрипція:** Білий курсив (`#FFFFFF`, italic).
- **Код / Терміни:** `#F59E0B` на темній плашці `rgba(0, 0, 0, 0.45)`.

---

## 3. Типографіка та Шрифти

- **UI шрифт:** `Plus Jakarta Sans`, `Segoe UI`, `system-ui`, без зарубок (sans-serif).
- **Моноширинний шрифт (хоткеї, код):** `JetBrains Mono`, `Consolas`, `monospace`.
- **Ієрархія:**
  - Заголовки (H1/H2): `font-weight: 800; letter-spacing: -0.02em;`
  - Підзаголовки: `font-weight: 700;`
  - Звичайний текст: `font-size: 13-14px; line-height: 1.5-1.6;`
  - Бейджі та теги: `font-size: 11-12px; font-weight: 800; text-transform: uppercase;`

---

## 4. Графіка та Віджети (QSS / CSS Guidelines)

### 1. Картки та вікна:
- **Радіус заокруглення:** `border-radius: 12px` (малі елементи) до `16px - 20px` (вікна та діалоги).
- **Тіні (Drop Shadow):** Розмиття `20px - 28px`, колір `rgba(0, 0, 0, 0.65)` або неонове сяйво золота `rgba(245, 158, 11, 0.25)`.
- **Безшовність:** Жодних білих підкладок! Скролбари — тонкі (4-6px), напівпрозорі, фон скрол-областей `background: transparent;`.

### 2. Кнопки (Buttons):
```css
/* Основна кнопка (Primary Accent) */
QPushButton.primary-btn {
    background: qlineargradient(x1:0, y1:0, x2:1, y2:1, stop:0 #F59E0B, stop:1 #D97706);
    color: #000000;
    font-weight: bold;
    border-radius: 10px;
    padding: 8px 16px;
    border: none;
}
QPushButton.primary-btn:hover {
    background: #FBBF24;
}

/* Вторинна кнопка (Glass / Outline) */
QPushButton.secondary-btn {
    background: rgba(255, 255, 255, 0.05);
    border: 1px solid rgba(255, 255, 255, 0.12);
    color: #F3F4F6;
    border-radius: 10px;
    padding: 8px 16px;
}
QPushButton.secondary-btn:hover {
    background: rgba(255, 255, 255, 0.12);
    border-color: #F59E0B;
}
```

### 3. Хоткеї (Kbd Pills):
- Компактні пігулки: темний прямокутник `#1F2937`, обводка `#374151` з нижнім бордюром 2px для 3D-ефекту натискання клавіші клавіатури, світлий моноширинний напис.

### 4. Кадрування арту манхви:
- Фіксоване співвідношення сторін для карток Anki: **16:10**.
- При кадруванні через `Alt + D` рамка зберігає ці пропорції, щоб зображення в Anki не деформувалися та мали єдиний візуальний формат галереї.
