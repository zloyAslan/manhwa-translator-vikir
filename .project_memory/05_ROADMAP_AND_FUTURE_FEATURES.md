## 2. Заплановані фундаментальні функції та модулі

Користувач зазначив потребу в додаванні кількох нових фундаментальних функцій та модулів. Нижче описано цільові напрямки та технічні точки розширення:

### 🎯 Напрямок А: Розширення інтелекту та розумного контексту (AI & NLP)
1. **Автоматичне визначення контексту фрейму:**
   - Можливість при захопленні слова автоматично зчитувати всю мовну хмаринку або сусідні репліки для передачі в Gemini як єдиний контекст сцени.
2. **Персоналізований словниковий профіль (CEFR / Рівень користувача):**
   - Відстеження слів, які користувач уже знає або додав в Anki, щоб ШІ підказував тільки нову або складну лексику.
3. **TTS нового покоління (Природне озвучення):**
   - Інтеграція високоякісного нейромережевого озвучення (Edge-TTS / ElevenLabs / локальний Silero) із вибором голосу під персонажів манхви.

### 🎯 Напрямок Б: Еволюція Читалки (Reader 2.0)
1. **Інтелектуальне авто-виділення хмаринок (Bubble Detection):**
   - Вбудована легка нейромережа детекції контурів баблів (YOLO / OpenCV mser), щоб можна було перекладати бабл в один клік без ручного малювання прямокутника.
2. **Оверлейний рендеринг перекладу безпосередньо поверх скану:**
   - Затирання оригінального тексту у вебтуні кольором фону бабла та накладання перекладеного тексту рідним шрифтом (Comic Inpainting / Typesetting).
3. **Синхронізація прогресу читання та закладок:**
   - Збереження поточної позиції скролу, історії прочитаних розділів та оцінок.

### 🎯 Напрямок В: Модульна екосистема та експорт
1. **Підтримка інших систем інтервальних повторень:**
   - Експорт не лише в Anki, а й у Quizlet, CSV/Notion або локальну тренувальну міні-гру прямо всередині комплексу.
2. **Розширення плагінної архітектури:**
   - Створення чіткого API для додавання нових джерел завантаження манхви (крім Telegram) та альтернативних OCR/LLM провайдерів (DeepSeek, Claude, локальний Ollama).

### 🎯 Напрямок Г: Навчальна система словацької мови B1-B2 через новели (Slovak Novel System)
*(Детальна специфікація описана в [06_SLOVAK_NOVEL_SYSTEM.md](file:///d:/всі%20проекти/перекладач/.project_memory/06_SLOVAK_NOVEL_SYSTEM.md))*
1. **Текстова читалка новел / ранобе в `manhwa_reader`:**
   - Вкладка «Новели / Ранобе» у бібліотеці, прихована за замовчуванням до першого завантаження через Telegram Downloader.
   - Чекбокс у завантажувачі: «Новела / Ранобе (EPUB / DOCX / TXT)».
   - Режим читання Zen/Dark Mode (монотонний темний фон, контрастний білий текст `#ffffff`, прогрес читання з точністю `X.X%`).
2. **Консольна утиліта пакетного перекладу глав:**
   - Легкий CLI-інструмент для пакетного перекладу глав новел на словацьку мову (Gemini API з підготовкою під DeepL).
   - Автоматична архівація оригіналів у `archive/` та складання результатів у бібліотеку читалки.
3. **Окремий спеціалізований перекладач (Slovak Novel Translator):**
   - Автономна полегшена утиліта (окремий скрипт / .exe без важкого OCR).
   - Суворий напрямок: Словацька -> Українська.
   - Хоткей `Alt + W`: згортання вікна, захоплення виділеного тексту мишкою у буфер безпосередньо в контекст Anki.
   - Спрощені картки Anki (Слово | Речення | Переклад) без графічних скріншотів.
   - ШІ-асистент на базі Gemini для швидких запитань щодо граматики та сленгу.

## 3. Правила реалізації нових функцій для розробника / ШІ:

1. **Не ламати автономність (Portability):**
   - Нові модулі не повинні вимагати встановлення глобальних системних драйверів або смітити в реєстрі.
2. **Дотримуватися палітри Dark Fantasy:**
   - Усі нові діалогові вікна, налаштування та плашки мають суворо використовувати стилі з [03_DESIGN_SYSTEM_AND_STYLE_GUIDE.md](file:///d:/всі%20проекти/перекладач/.project_memory/03_DESIGN_SYSTEM_AND_STYLE_GUIDE.md).
3. **Пам'ятати про потоки в PyQt6:**
   - Усі тривалі мережеві запити (Gemini API, завантаження розділів, TTS) **ОБОВ'ЯЗКОВО** виконувати у фонових потоках (`QThread` / `QRunnable` / `asyncio`), щоб інтерфейс не зависав під час читання.
4. **Оновлювати цю глобальну пам'ять:**
   - При додаванні нових файлів або кардинальних змінах архітектури негайно актуалізувати відповідні `.md` файли в `.project_memory/`.
